# Rock Paper Scissors

A beginner-friendly **Rock Paper Scissors** game built in Python that allows players to compete against the computer through a command-line interface. The game features multiple game modes, score tracking, replay functionality, and randomly generated computer moves.

## Features

* Play against the computer
* Three game modes:

  * Best of 3
  * Best of 5
  * Best of 7
* Random computer move generation
* Score tracking
* Input validation
* Replay option after each game
* Interactive command-line interface

## Technologies Used

* Python 3

## Python Concepts Used

* Functions
* Variables and Data Types
* Dictionaries
* Loops (`while`)
* Conditional Statements (`if`, `elif`, `else`)
* User Input Validation
* Random Module


Created as a Python practice project.
